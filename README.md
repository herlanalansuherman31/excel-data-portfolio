# 📊 Excel Data Analytics Portfolio

Selamat datang di repositori portofolio Microsoft Excel saya. Repositori ini dibuat sebagai rekam jejak digital dalam menguasai keterampilan pengolahan data, pembersihan data (*data cleaning*), hingga formula tingkat lanjut (*advanced formulas*) yang krusial untuk kebutuhan administrasi, analisis kredit, dan pelaporan bisnis.

---

## 📂 Struktur & Daftar Isi Repositori

Setiap folder di bawah ini dilengkapi dengan file dataset latihan (`.xlsx`) dan catatan ringkas implementasinya:

### 🧼 [01. Data Cleaning Essentials](./01-Data-Cleaning-Essentials/)
Folder ini berisi teknik-teknik fundamental dalam merapikan data mentah yang berantakan agar siap dianalisis.
* **Fokus Keterampilan:** *Autofit rows/columns, Wildcard Find & Replace, Text to Columns, Removing Duplicates, Handling Blanks (Go To Special).*
* **Rumus Utama:** `TRIM`, `PROPER`, `UPPER`, `LOWER`, `IFERROR`.

### 🧮 [02. 25+ Rumus Produktivitas Paling Penting](./02-25-Rumus-Paling-Penting/)
Folder ini berisi penerapan 25+ formula wajib Excel untuk efisiensi kerja sehari-hari, manipulasi teks, hingga logika bertingkat.
* **Fokus Keterampilan:** Logika kelulusan, peringkat data, pembulatan grosir, dan penarikan data antar tabel referensi.
* **Rumus Utama:** `SUMIF`, `COUNTIF`, `RANK`, `VLOOKUP`, `HLOOKUP`, `ROUND`, `FLOOR`, `CEILING`, `MID`, `LEFT`, `RIGHT`.

---

## 🛠️ Keterampilan & Perangkat Alat
* **Perangkat Lunak:** Microsoft Excel 
* **Kompetensi Utama:** Pembersihan Data, Manajemen Data String/Teks, Formula Logika, Analisis Tabel Referensi (*LookUp*).
